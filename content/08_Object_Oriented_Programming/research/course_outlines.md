## 1. Object Oriented Programming in Java Specialization

**Platform:** Coursera
**Instructor(s):** Leo Porter, Christine Alvarado, Mia Minnes (UC San Diego); Andrew D. Hilton, Robert Duvall, Susan H. Rodger, Owen Astrachan (Duke University)
**Rating:** 4.6/5 (15,062 reviews, 116,212+ learners)
**Duration:** ~115 hours across 4 courses (6 months at 10 hours/week)
**Level:** Beginner
**URL:** https://www.coursera.org/specializations/object-oriented-programming

### Curriculum

#### Course 1: Java Programming: Solving Problems with Software (18 hours)
- Editing, compiling, and running Java programs
- Conditionals and loops
- Java API documentation
- Debugging using scientific method
- Method creation and problem-solving
- Test case development
- Multi-method class design
- Divide-and-conquer techniques
- **Project:** CSV data analysis program (baby name popularity trends)

#### Course 2: Java Programming: Arrays, Lists, and Structured Data (15 hours)
- File reading and writing
- Data file problem-solving
- Quantitative data analysis (maximums, minimums, averages)
- Array and ArrayList storage and manipulation
- Multi-class integration
- Iterables and collections (including maps)
- **Project:** Encryption program and algorithm-breaking application

#### Course 3: Object Oriented Programming in Java (40 hours)
- Object-oriented fundamentals
- Graphical user interface programming
- Leveraging existing libraries
- Core sorting and searching algorithms
- Event-driven programming
- Interactive data visualization
- Geospatial mapping
- **Project:** Interactive map for geospatial data visualization

#### Course 4: Data Structures and Performance (42 hours)
- Linked lists, trees, and hashtables
- Data structure efficiency analysis
- Asymptotic Big-O analysis
- Performance optimization strategies
- Data retrieval, addition, and deletion efficiency
- Memory usage optimization
- **Project:** Large-scale textual data management application

## 2. Java Programming MOOC (Parts I & II)

**Platform:** MOOC.fi (University of Helsinki)
**Instructor(s):** University of Helsinki Department of Computer Science
**Rating:** Highly rated on Class Central; one of the most recommended free Java courses
**Duration:** 14 parts, each requiring 5–20 hours (estimated 140–280 hours total)
**Level:** Beginner to Intermediate
**URL:** https://java-programming.mooc.fi/

### Curriculum

#### Java Programming I

##### Part 1: Programming Fundamentals
- Printing and program execution
- Reading user input and string handling
- Variables (string, integer, floating-point, boolean types)
- Arithmetic calculations
- Conditional statements and logical operators

##### Part 2: Repetition and Methods
- Recurring problem patterns
- Loop structures (while, for loops)
- Loop control (break, continue statements)
- Method creation, parameters, and return values
- Call stack concepts

##### Part 3: Data Structures and Strings
- Error detection and debugging techniques
- List data structure operations
- Array creation and manipulation
- String operations and splitting

##### Part 4: Object-Oriented Basics
- Class and object concepts
- Constructors and instance variables
- Object methods and initialization
- File input and filesystem operations
- Objects within collections

##### Part 5: Advanced OOP Concepts
- Object-oriented design principles
- Method and constructor overloading
- Primitive versus reference variables
- Null references and NullPointerException
- Object comparison using equals()

##### Part 6: Complex Objects and Testing
- Nested object structures
- User interface separation from logic
- Unit testing fundamentals
- Test-driven development introduction

##### Part 7: Paradigms and Algorithms
- Programming paradigm concepts
- Selection sort algorithm
- Linear and binary search algorithms
- Extended programming projects

#### Java Programming II

##### Part 8: Data Structure Review

- HashMap introduction and usage

##### Part 9: Inheritance and Interfaces
- Class inheritance mechanics
- Superclass and subclass relationships
- Interface definition and implementation
- Polymorphism and object type representation

##### Part 10: Collections and Advanced Techniques
- Stream handling and lambda expressions
- Comparable interface implementation
- Sorting with multiple criteria
- Regular expressions and enumerated types
- Iterator pattern usage

##### Part 11: Structure and File Management
- Class diagram interpretation
- Package organization
- Exception handling and throwing
- File reading and writing operations

##### Part 12: Generics and Data Structures
- Type parameters and generic classes
- ArrayList and HashMap implementation
- Random number generation
- Multidimensional arrays

##### Part 13: Graphical User Interfaces
- GUI component creation and configuration
- Event handling mechanisms
- Application launch parameters
- Multi-view interface design

##### Part 14: Visualization and Libraries
- Data visualization techniques
- Multimedia integration (graphics, audio, images)
- Interactive application development (Asteroids game)
- Maven and third-party library integration

## 4. Object-Oriented Design & Design Patterns (Software Design and Architecture Specialization)

**Platform:** Coursera
**Instructor(s):** Kenny Wong (University of Alberta)
**Rating:** 4.7/5 (2,412 reviews for OO Design; 1,375 reviews for Design Patterns)
**Duration:** ~32 hours across 2 courses (OO Design: 17 hours; Design Patterns: 15 hours)
**Level:** Intermediate
**URL:** https://www.coursera.org/specializations/software-design-architecture

### Curriculum

#### Course A: Object-Oriented Design (17 hours, 156,146+ learners)

##### Module 1: Object-Oriented Analysis and Design (4 hours)
- Software design roles in industry
- Object-oriented modeling fundamentals
- Software requirements, conceptual and technical designs
- Competing design qualities and trade-offs
- CRC (Class Responsibility Collaborator) cards
- User story requirements expression
- Java proficiency quizzes

##### Module 2: Object-Oriented Modeling (4 hours)
- Abstraction in Java and UML
- Encapsulation principles
- Decomposition techniques

- UML class diagram creation

##### Module 3: Design Principles (7 hours)
- Coupling and cohesion trade-offs
- Separation of concerns
- Information hiding
- Conceptual integrity
- Inheritance pitfalls and solutions
- UML sequence diagrams
- UML state diagrams
- Model checking techniques
- **Capstone:** UML Sequence and State Diagrams

##### Module 4: Capstone Challenge (2 hours)
