# Postgres — Technology Concepts

Placeholder technology-level concept overview for PostgreSQL.

## Core Ideas

- ACID-compliant relational database with strong SQL standards support
- MVCC (Multi-Version Concurrency Control) allows readers not to block writers
- Highly extensible: custom types, operators, index types, procedural languages
- Rich JSON/JSONB support for semi-structured data alongside relational data

## Key Topics

- Indexes (B-tree, GIN, GiST, partial)
- Query optimization and EXPLAIN
- Transactions and isolation levels
- Replication and high availability
- VACUUM and autovacuum
- Window functions and CTEs
