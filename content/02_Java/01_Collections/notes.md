# Collections

Placeholder notes for Java Collections.

## Key Points

- The Java Collections Framework provides interfaces (`List`, `Set`, `Map`, `Queue`) and implementations
- `ArrayList` vs `LinkedList`: array-backed random access vs pointer-linked insertion
- `HashMap` uses hashing; `TreeMap` maintains sorted order; `LinkedHashMap` preserves insertion order
- `Collections.unmodifiableList()` wraps a list to prevent mutation

## Common Implementations

| Interface | Common Implementations |
|-----------|----------------------|
| List      | ArrayList, LinkedList |
| Set       | HashSet, TreeSet, LinkedHashSet |
| Map       | HashMap, TreeMap, LinkedHashMap |
| Queue     | ArrayDeque, PriorityQueue |
